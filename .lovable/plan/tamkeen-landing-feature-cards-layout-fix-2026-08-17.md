# TAMKEEN_LANDING_FEATURE_CARDS_LAYOUT_FIX

هدف: تحسين بطاقات المزايا في الصفحة الرئيسية لاستغلال المساحة الفارغة في أعلى البطاقة، وإزالة التكرار في بطاقة الثالث الثانوي.

## Scope
- ملف واحد فقط: `src/routes/index.tsx`
- لا تغييرات backend / DB / migration / RLS / RPC / publish

## Changes

### 1. ترتيب البطاقة (FeaturesSection)
```text
الآن:  أيقونة (فوق) → عنوان (تحت) → وصف (تحت)
الهدف: أيقونة + عنوان في صف واحد أفقي → الوصف تحته
```
- تغيير هيكل البطاقة ليحتوي على صف header أفقي يجمع الأيقونة والعنوان.
- في RTL: الأيقونة على اليمين، العنوان بجانبها يساراً، مع `gap-2` أو `gap-3`.
- العنوان يسمح بالتفاف السطر إذا كان طويلاً (`leading-snug`, `min-w-0`).
- الوصف يبقى تحت الصف الأفقي.
- الاستمرار في استخدام الـ tokens الدلالية (text-card-foreground, text-muted-foreground, الخلفيات الموجودة في `cardClass` / `iconClass`) وعدم استخدام ألوان ثابتة.

### 2. إعادة صياغة بطاقة الثالث الثانوي
- التكرار الحالي: "نماذج الاختبارات الوزارية السابقة" مكرّر في البطاقة الثانية.
- العنوان المقترح: `مراجعة مركّزة للثالث الثانوي`
- الوصف المقترح: `خطة يومية ومراجعة شاملة للمادة والأخطاء قبل الامتحان النهائي.`
- إذا أردت صياغة مختلفة، يمكن تعديلها قبل بدء التنفيذ.
