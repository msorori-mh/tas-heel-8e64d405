## ما تم التحقق منه فعلياً

- صفحة الدرس `src/routes/_authenticated/lessons.$lessonId.tsx` تحتوي 7 بطاقات `JourneyCard` بأرقام ثابتة
(1 اقرأ الدرس، 2 الخريطة الذهنية، 3 التجربة العملية، 4 الملخص، 5 اختبر فهمك، 6 اختبار الدرس، 7 موارد إضافية).
- التقدم يُحسب بأوزان ثابتة: 5 عناصر × 20% لكل عنصر — أي أن الدرس ذا المحتوى الوحيد الكامل لا يتجاوز 20%.
- البطاقة السابعة تعرض داخلها أربع بطاقات فرعية (خرائط/فيديو/تجربة/موارد) كلٌّ منها برسالة «لا يوجد» مستقلة.
- المورد الأساسي مدعوم فعلاً في البيانات: `lesson_resources.is_primary` + `lessons.delivery_mode`،
وصفحة الدرس تقرأه بالفعل (`primaryResource`) لكن تعرضه فقط عند `delivery_mode` خارجي أو غياب محتوى الكتاب.
- دروس القرآن الحالية `delivery_mode = in_app_content` وبلا محتوى وبلا موارد (نتيجة تشخيص 18A)،
ولذلك تظهر «اقرأ الدرس — غير متوفر». هذا صحيح تقنياً وسيُحل باسترجاع 18A.

## 1) نموذج قدرات الدرس (Lesson Capability Model)

وحدة واحدة جديدة `src/lib/lessons/lesson-capabilities.ts` تستقبل ما تم تحميله فعلاً للدرس
وتُخرج قائمة الأنشطة المتاحة مرتبة تربوياً:

```text
PRIMARY_CONTENT   نص الكتاب  أو  المورد الأساسي (PDF/رابط خارجي)
SUMMARY           ملخص نصي أو ملخص HTML منشور
EXPLANATION       شروحات إضافية
MINDMAP           خريطة ذهنية (HTML أو مورد mindmap)
PRACTICAL         تجربة عملية (HTML أو مورد experiment)
VIDEO             فيديو
ASSESSMENT        أسئلة «اختبر فهمك»
LESSON_EXAM       اختبار تدريبي للدرس
EXTRA_RESOURCES   موارد لم تُصنَّف ضمن ما سبق
```

قاعدة صارمة: **القدرة غير الموجودة غير موجودة** — لا بطاقة، لا رقم خطوة، ولا سطر «غير متوفر».
لا يوجد أي نشاط افتراضي مرتبط بنوع المادة؛ الحاكم هو ما أُدخل للدرس فعلاً.

## 2) إعادة بناء صفحة الدرس

- الترقيم يُشتق من الأنشطة المتاحة: درس بـ PDF + ملخص + أسئلة يعرض 1، 2، 3 فقط.
- المحتوى الأساسي بطاقة واحدة:
  - محتوى داخل التطبيق → «اقرأ الدرس».
  - مورد أساسي خارجي/PDF → «افتح الدرس» ويفتح المورد الأساسي مباشرة، حتى لو كان `delivery_mode = in_app_content`
  (وجود مورد أساسي صالح كافٍ). يُمنع ظهور «اقرأ الدرس — غير متوفر» في هذه الحالة.
- لا يوجد محتوى أساسي إطلاقاً → **حالة واحدة فقط**: «محتوى الدرس لم يُضف بعد»،
مع إخفاء بقية البطاقات غير المتاحة، ورابط رجوع للمادة.
- قسم «موارد إضافية» يظهر فقط عند وجود مورد واحد على الأقل، ويعرض الأنواع الموجودة فقط.
عند عدم وجود موارد لا يظهر القسم ولا أي بطاقة فرعية فارغة.

## 3) التقدم الديناميكي

المقام = عدد الأنشطة المتاحة القابلة للتتبع لهذا الدرس فقط.
مثال: PDF + ملخص + أسئلة → كل نشاط مكتمل = 33%. الأنشطة غير الموجودة لا تدخل الحساب مطلقاً.

## 4) العنوان والمسار (عرض فقط)

عناوين دروس القرآن تحمل التسلسل كاملاً داخل `lessons.title`
(«الفصل الأول - أولاً الحفظ والتفسير - الدرس الأول - سورة السجدة: …») وهو قادم من ملف الاستيراد.

- **لا تُنشأ وحدات وهمية ولا يُعدَّل أي صف في القاعدة.**
- طبقة عرض فقط: يُفصل العنوان إلى سطر سياقي صغير (الفصل / المسار / رقم الدرس) وعنوان رئيسي مختصر
(«سورة السجدة: مراجعة الآيات الكريمة والدلالات»)، مع منع تكرار نفس الجزء في المسار العلوي.
- التوصية التشغيلية بتنظيف العناوين من المصدر تُوثَّق في التقرير ضمن عقد المشغّل، دون تنفيذ تعديل جماعي.

## 5) إشارة «جاهز للطالب» في الإدارة

في قائمة الدروس بلوحة الإدارة (`admin.lessons`) وصفحة الدرس الإدارية:
شارات القدرات الفعلية لكل درس + حكم صريح:

```text
Lesson imported = YES
Student ready   = NO
Reason          = PRIMARY CONTENT MISSING
```

الدرس لا يُعتبر `STUDENT_READY` إلا بوجود محتوى أساسي صالح (نص كتاب أو مورد أساسي).
هذه قراءة من نفس الجداول الحالية — لا أعمدة جديدة ولا Migration.

## 6) مصفوفة الاختبار


| الحالة                   | المتوقع                              |
| ------------------------ | ------------------------------------ |
| قرآن: PDF فقط            | بطاقة واحدة «افتح الدرس»             |
| قرآن: PDF + ملخص         | خطوتان                               |
| قرآن: PDF + ملخص + أسئلة | ثلاث خطوات                           |
| قرآن: بلا تجربة          | بطاقة التجربة غير موجودة نهائياً     |
| درس بلا موارد إضافية     | قسم الموارد مخفي بالكامل             |
| كيمياء بتجربة حقيقية     | بطاقة التجربة تظهر                   |
| درس بلا أي محتوى         | حالة واحدة «محتوى الدرس لم يُضف بعد» |
| التقدم                   | المقام = الأنشطة المتاحة فقط         |
| الترقيم                  | متتابع بلا فجوات                     |


يُضاف اختبار ثابت (static test) يمنع عودة الافتراض الثابت: لا `stepNumber` حرفي، ولا أوزان تقدم ثابتة.
تُلتقط لقطات Playwright لدرس قرآن ودرس بمحتوى غني للتحقق البصري RTL.
