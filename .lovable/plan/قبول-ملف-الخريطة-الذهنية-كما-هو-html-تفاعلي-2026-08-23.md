# قبول ملف الخريطة الذهنية كما هو (HTML تفاعلي)

## المشكلة
ملف الخريطة الذهنية يُرفض لأن النظام يعامله كـ«HTML ثابت»: ممنوع `<script>`، ممنوع `onclick`، ووسم viewport إلزامي. ملفك يحتوي جافاسكربت وتفاعلات، وهذا مطلوب لعمل الخريطة.

## الحل
اعتبار «الخريطة الذهنية» مكوّنًا تفاعليًا مثل «التجارب المعملية»، فيُقبل الملف كما هو دون تعديل يدوي.

### ما سيتغير
1. تحويل ملف الخريطة الذهنية إلى ملف الاستيراد التفاعلي: يُسمح بـ `<script>` وبمعالجات الأحداث المضمّنة (`onclick` وغيرها).
2. وسم viewport يصبح تنبيهًا لا خطأً يمنع القبول (يبقى الاقتراح ظاهرًا فقط كملاحظة).
3. تبقى قاعدة واحدة صارمة لأسباب أمنية: ممنوع تحميل مصادر خارجية (روابط CDN/خطوط عن بُعد) — يجب أن يكون كل شيء داخل الملف. هذا ضروري ليعمل المحتوى أوفلاين وداخل الحماية.
4. قبول رفع الخريطة كملف `.html` أو حزمة `.zip` تحتوي `index.html` (نفس ما هو متاح للتجارب).
5. تحديث نص الإرشادات داخل بطاقة «الخريطة الذهنية» ليقول: HTML تفاعلي مسموح فيه JavaScript، بدون مصادر خارجية.

### الأمان
الخريطة الذهنية تُعرض للطالب داخل إطار معزول `sandbox="allow-scripts"` (نفس مسار المحتوى التفاعلي)، لذلك تشغيل JavaScript داخلها لا يعرّض حساب الطالب أو البيانات للخطر.
