# إصلاح سلوك رفع الملفات وتنزيل القوالب في مركز الاستيراد

## ما يحدث فعليًا

عند اختيار ملف للخريطة الذهنية أو التجارب أو ملفات Excel، النظام **يفحص الملف ويرفضه**، لكن رسالة الرفض تُعرض في أسفل الصفحة بعيدًا عن بطاقة المكوّن، فتبدو البطاقة فارغة وكأن «لا شيء ينفّذ».

أسباب الرفض المؤكدة من الكود:

- ملفات HTML تُفحص مقابل معيار صارم: يجب أن تحتوي `dir="rtl"` ووسم `viewport`، وبدون أي مصدر خارجي (CDN) أو معالجات `onclick`، وبدون `<script>` نهائيًا في الملفات الثابتة (الشرح، الملخص، الخريطة الذهنية). أغلب ملفات الخريطة الذهنية الجاهزة تحتوي سكربت أو خطوط/مكتبات خارجية، لذلك تُرفض.
- ملفات Excel: تُحوَّل داخليًا إلى JSON، وأي عمود إلزامي مفقود أو خيارات غير أربعة يوقف العملية برسالة تظهر أيضًا في أسفل الصفحة.

أما زر «تنزيل القالب» فيستخدم رابطًا مباشرًا؛ داخل إطار المعاينة لا يُنفَّذ التنزيل بل يُعرض محتوى ملف xlsx الثنائي كرموز غير مفهومة. (القوالب 09 و10 موجودة فعلًا في المشروع.)

## الإصلاحات

### 1. إظهار سبب الرفض داخل البطاقة نفسها
- عرض رسالة الخطأ الخاصة بكل مكوّن أسفل حقل اختيار الملف مباشرة (إطار أحمر) بدل الرسالة الواحدة في نهاية الصفحة، مع سرد كل المخالفات لا أول ثلاث فقط.
- إبقاء اسم الملف المرفوض ظاهرًا مع زر «إزالة/إعادة المحاولة» حتى يعرف المستخدم أن الاختيار وصل فعلًا.
- إضافة تمرير تلقائي إلى البطاقة عند حدوث الخطأ.

### 2. رسائل عربية إرشادية بدل رموز المعيار
تحويل كل رمز مخالفة إلى جملة تصحيحية، مثل:
- «الملف لا يحتوي `dir="rtl"` — أضِف السمة إلى وسم html».
- «الملف يحتوي كود JavaScript — الخريطة الذهنية والشرح والملخص يجب أن تكون HTML ثابت».
- «الملف يشير إلى مصدر خارجي (خط أو مكتبة على الإنترنت) — ضمِّن الأنماط داخل الملف».
- «وسم viewport مفقود».

مع سطر توضيحي دائم في بطاقة الخريطة الذهنية والتجارب يبيّن الشروط قبل الاختيار.

### 3. تجربة معملية بصيغة أوسع
قبول ملف HTML تفاعلي يحتوي JavaScript داخل البطاقة كما هو مسموح بالمعيار، وتوضيح أن الحزمة ZIP مقبولة أيضًا (index.html بالداخل)، مع رسالة صريحة عند فشل استخراج الحزمة.

### 4. إصلاح تنزيل القوالب
تحويل الزر إلى تنزيل عبر جلب الملف كـ Blob ثم حفظه باسمه (مع فتحه في تبويب جديد كخطة بديلة)، حتى لا تُعرض رموز ثنائية داخل المعاينة.

### 5. أخطاء Excel أوضح
- عرض اسم العمود المفقود أو رقم الصف المخالف داخل البطاقة.
- رسالة صريحة إذا تعذّر قراءة الملف أصلًا (ملف تالف أو ليس xlsx).
- إظهار عدد الأسئلة المقروءة عند النجاح.

## نطاق العمل

واجهة وعرض رسائل فقط: `src/components/admin/GoldenLessonPackageBuilder.tsx` مع دوال ترجمة الرسائل. لا تغيير في قواعد الأمان أو المعيار أو قاعدة البيانات.
