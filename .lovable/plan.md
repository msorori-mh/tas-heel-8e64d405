# CURRICULUM_CONTENT_ENTRY_READINESS_13 — إغلاق تشغيلي مع الضوابط الخمسة

القيود: لا كتابة على بيانات المنهج، لا إدخال محتوى إنتاجي، لا بيانات وهمية. الاختبارات تعتمد fixtures / تحليل كود فقط.

## 1. SUBJECT_AS_BRANCH — إتمام القواعد
- عقد Template 01 والقالب وواجهة CRUD يحملون `group_code` و `group_name` (اختياريان).
- قواعد التعديل في واجهة المادة:
  - `subject_code`: يُحدد عند الإنشاء فقط، غير قابل للتعديل بعدها.
  - `group_code`: يُسمح بتعيينه لاحقاً فقط عندما يكون فارغاً؛ بعد أن تصبح المادة مستخدمة (وحدات/دروس/أسئلة/نشاط) يُقفل في الواجهة.
  - `group_name`: تسمية عرض قابلة للتعديل دائماً.
- تحقق تناسق: نفس الصف + نفس المسار + نفس `group_code` ⇒ نفس `group_name` (تحقق في العقد/الاستيراد وفي حوار التحرير).
- حارس دلالي: `group_code` لا يظهر في أي مسار صلاحيات (RLS، `can_access_subject`، `question_targets`).

ملاحظة قائمة حالياً: قفل `group_code` بعد التعيين مطبّق على مستوى قاعدة البيانات (trigger موجود مسبقاً)، فالقفل «بعد الاستخدام» يُطبّق كطبقة واجهة فوقه — بدون ترحيل جديد.

## 2. إغلاق مسارات الحذف المباشرة
- التأكد أن حوارات الحذف القديمة للمواد/الوحدات/الدروس لم تعد موجودة، والمسار الوحيد:
  معاينة RPC ← عرض الأثر والموانع ← Full Admin فقط ← `admin_curriculum_delete` ← سجل تدقيق.
- `content_manager`: معاينة نعم، حذف نهائي لا (حتى لو رأى الحوار).
- اختبار ثابت يفحص كود لوحة الإدارة ويثبت: عدد مسارات الحذف المباشر على جداول المنهج = 0.

## 3. مصفوفة صلاحيات المشغّل (يوسف)
توثيق واختبار للمصفوفة:
- 01–07 إنشاء/تعديل/استيراد: مسموح
- Validate / Prepare / Execute: مسموح
- 09 استيراد أسئلة كمسودات: مسموح
- حذف نهائي / إدارة مستخدمين وأمان / نشر بنك الأسئلة / نشر المحتوى: ممنوع بدون صلاحية منفصلة
- سير العمل الرسمي: يوسف 01→07→09 ← مراجع ← ناشر ← يوسف 08.

## 4. مركز الاستيراد = صفحة تشغيل
- إزالة أي بقايا: POC المحافظات، «قريباً»، «التنفيذ لاحقاً»، «تفاصيل الأخطاء لاحقاً».
- شريط ترتيب واضح أعلى الصفحة: 01→02→03→04→05→06→07→09→Review→Publish→08، مُشتق من `IMPORT_EXECUTION_ORDER` فقط (مصدر واحد للقائمة المنسدلة والنص).
- سجل العمليات بأعمدة: القالب، الملف، الصفوف، مُدرج، مُحدّث، متجاوَز، محجوب، أخطاء، الحالة، المشغّل، التاريخ. المشغّل يُشتق من `created_by` الحقيقي في `import_jobs` (اسم من الملف الشخصي عند توفره، وإلا معرّف مختصر) — بدون أي قيمة وهمية.

## 5. حزمة يوسف الرسمية
- مجلد حزمة واحد يجمع القوالب التسعة + `NAMING-CONVENTION` + `DATA-DICTIONARY-AR` + `CONTENT-OPERATOR-GUIDE-AR`.
- الدليل يتضمن مثالين صريحين: مادة ← وحدة ← درس، ومادة ← درس مباشرة، ومثال مواد متفرعة (مجموعة «اللغة العربية»: النحو والصرف، البلاغة، الأدب) مع تنبيه أن المجموعة ليست مستوى صلاحية ولا Question Target.

## ملاحظة واحدة تحتاج قرارك
دعم `group_code/group_name` داخل تنفيذ الاستيراد على مستوى الخادم يحتاج تحديث دالة `import_execute_template`؛ الملف جاهز غير مطبّق في `supabase/migrations-pending/`. التزاماً بـ NEW MIGRATION = NOT EXPECTED سيبقى معلقاً في هذه المرحلة، ويُنفَّذ الجزء الواجهي والعقد فقط، ويُدرج التطبيق كخطوة مستقلة لاحقة.
