# MANUAL-GRADING-UX-FLOWS-01
## تدفقات رحلة المستخدم والتصميم البصري لمحرك التصحيح اليدوي (RTL & Mobile-First UX)

> **وثيقة تدفقات رحلة المستخدم والتصميم البصري (UX Flows & Visual Design Document)**  
> **الإصدار:** 1.0.0  
> **الحالة:** مجمد للتصميم (Design Frozen - No Code / No SQL Execution)  
> **النظام:** منصة تسهيل التعليمية (Tas-heel Engine - Question Bank QB-01)  

---

## 1. فلسفة التصميم البصري ودعم اللغة العربية (Visual Design & Arabic RTL System)

### 1.1. الهوية البصرية الجذابة (Rich Modern Aesthetics)
- **أنظمة الألوان المتقدمة**: اعتماد درجات ألوان متناغمة ومصممة للحد من إجهاد العين أثناء جلسات التصحيح الطويلة:
  - الوضع الداكن الفاخر (Sleek Dark Mode): خلفيات بتركيبات `Slate-900` و `Zinc-950` مع لمسات زجاجية شبه شفافة (Glassmorphism Effects) وعناصر إضاءة محيطية (Subtle Ambient Glows).
  - الوضع الفاتح الناصع (Clean Light Mode): خلفيات `Emerald-50/Off-White` مع تباين مرتفع للنصوص لضمان وضوح قراءة إجابات الطلاب الخطية والمطبوعة.
- **الأنيميشن والتفاعل الديناميكي (Micro-Animations & Dynamic Feedback)**:
  - انتقالات سلسة (Smooth 200ms Easing Transitions) عند الانتقال بين إجابات الطلاب.
  - إشارات مرئية فورية تفاعلية عند اختيار بنود سلم التقييم (Rubric Chips Accent) لتأكيد الاختيار بدون تشتيت.

### 1.2. دعم اللغة العربية والربط ثنائي الاتجاه (Arabic RTL & BiDi Handling)
- **المحاذاة الشاملة من اليمين لليسار (RTL System)**:
  - كافة عناصر التحكم، الأزرار، القوائم الجانبية، والرموز الهيكلية تتجه من اليمين إلى اليسار بشكل فصيح ومجرد من أي تشويه تركيبي.
  - استخدام خطوط عربية حديثة وعالية الجودة (مثل Cairo و Inter مع دعم الخطوط المعايرة للرموز والأرقام العربية/الإنجليزية).
- **معالجة النصوص ثنائية الاتجاه (BiDi Engine)**:
  - محاذاة النص العربي لليمين أثناء استعراض الإجابات المقالية، مع المحافظة التلقائية على محاذاة اليسار (LTR) للرموز البرمجية، الصغ المعتمدة، والمعادلات الرياضية والهندسية لضمان عدم تلف تركيبتها.

### 1.3. التصميم المخصص للموبايل والتابلت أولاً (Mobile-First & Tablet Responsive UX)
- **أهداف لمسية فائقة الاستجابة (Touch Targets >= 48px)**:
  - تصميم أزرار التقييم ومؤشرات الدرجات بمساحات لمس واسعة تمنع الأخطاء أثناء اللمس بالأصابع على الأجهزة المحمولة.
- **التنسيق العمودي والأدراج السفلية (Responsive Drawer Sheets)**:
  - في شاشات الجوال: عرض إجابة الطالب في اللوحة الرئيسية مع درج سفلي قابل للسحب (Bottom Sheet) ينزلق بسلاسة لعرض سلم التقييم (Rubric) وحقول الملاحظات.
  - في شاشات التابلت والشاشات الكبيرة: التوزيع المزدوج (Dual Pane Layout) بإجابة الطالب في الجانب الأيمن وسلم التقييم في الجانب الأيسر.

## 2. تدفقات ورحلات المستخدم الخمس التفصيلية (5 Core User Journeys)

### 2.1. الرحلة الأولى: رحلة المصحح (Grader Journey - Queue to Submit)

```
[طابور الإجابات (Queue)] 
       │
       ▼
[اختيار وتخصيص إجابة (Claim Response)]
       │ (إنشاء قفل مؤقت Lease Lock)
       ▼
[شاشة التصحيح المزدوجة (Evaluation Screen)]
   ├── الأيمن: إجابة الطالب المقالية (مجهولة الهوية)
   └── الأيسر/الدرج السفلي: سلم التقييم (Rubric) + الإجابة النموذجية
       │
       ▼
[اختيار بنود Rubrics + إدخال الدرجات الجزئية + الملاحظات]
       │ (تحقق من الحدود: 0 <= Score <= Max)
       ▼
[اعتماد وإرسال التقييم (Submit Grade)]
       │
       ▼
[العودة التلقائية للطابور / جلب الإجابة التالية]
```

#### تفاصيل الشاشة الرئيسية للمصحح (Grader Screen Layout):
1. **شريط الهيدر العلوي**:
   - مؤقت القفل النشط (Lease Lock Countdown Timer - مثلاً `14:32 متبقية`).
   - شارة المادة والرقم التسلسلي المجهول للإجابة (`#EXP-8942`).
   - زر تحرير الإجابة (Release Claim).
2. **لوحة عرض إجابة الطالب (Student Response Viewer)**:
   - تكبير/تصغير الخط، دعم الألوان المحسنة، إمكانية وضع علامات توضيحية مظللة على أجزاء الإجابة.
3. **لوحة التقييم وسلم الدرجات (Rubric Evaluator Panel)**:
   - بنود سلم التقييم مقسمة في كروت لمسية تفاعلية.
   - عند النقر على مستوى التقييم (مثلاً: "ممتاز - 4 درجات") يتم تحديث حقل الدرجة المخصصة آلياً.
   - حقل ملاحظات الطالب (Student Feedback) وحقل الملاحظات السرية للمراجع (Internal Note).
4. **شريط الإجراءات السفلي الثابت (Sticky Action Bar)**:
   - إجمالي الدرجة الحالية (`8.5 / 10.0`).
   - زر إرسال التقييم ("اعتماد وتسليم الدرجة").

---

### 2.2. الرحلة الثانية: رحلة المصحح الأول والمراجع (Senior Grader & Reviewer Journey)

```
[طابور المراجعة والعينات (Moderation Queue)]
       │
       ├── خيار أ: عينات عشوائية (Random QA Audit)
       └── خيار ب: حوادث التباين المزدوج (Double Marking Variance Alert)
       ▼
[شاشة المعايرة والتحكيم (Arbitration & Review Screen)]
   ├── استعراض تقييم المصحح الأول
   ├── استعراض تقييم المصحح الثاني (في التصحيح المزدوج)
   └── استعراض الفروقات وبنود Rubric الخلافية
       │
       ├── مسار أ: تأكيد التقييم واعتماده النهائي (`FINALIZED`)
       └── مسار ب: رفض التقييم وإعادته للمصحح (`RETURNED_FOR_REVIEW`) مع ملاحظات توجيهية
```

#### ميزات شاشة التحكيم (Arbitration Interface):
- **مقارنة التقييمات الشاقولية (Side-by-Side Comparison)**: عرض درجتي المصححين جنبًا إلى جنب مع إبراز المعايير التي وقع فيها الانحراف بـ "لون تنبيهي خفيف".
- **زر إعادة الإرجاع التوجيهي (Return with Guidance)**: زر مخصص لإعادة المهمة مع نافذة حوارية إجبارية لكتابة توجيهات المصحح الأول.

---

### 2.3. الرحلة الثالثة: رحلة مدير التصحيح (Grading Manager Journey - Operations Dashboard)

```
[لوحة التحكم والعمليات المباشرة (Operations Dashboard)]
       │
       ├── مؤشرات الأداء الحية (SLA Breach Metrics, Completion Rate)
       ├── طابور التوزيع والتحكم في حمولة المصححين (Workload Balancing)
       └── إدارة الاعتراضات والتظلمات (Appeals Management)
       │
       ▼
[إعادة التخصيص اليدوي / تعديل السعة / بث التنبيهات]
       │
       ▼
[اعتماد وإغلاق الدفعة الامتحانية (Trigger Batch Finalization)]
       │ (تنشيط إشعارات الطلاب وكشف الإجابات النموذجية)
```

#### مكونات لوحة تحكم مدير التصحيح:
- **بطاقات المؤشرات السريعة (KPI Cards)**: إجمالي الإجابات، الإجابات المعتمدة، الإجابات قيد التصحيح، الحوادث المتبقية المتجاوزة لـ SLA.
- **مخطط أداء المصححين**: عرض متوسط زمن تصحيح الإجابة لكل مصحح، معدل التباين، وعدد الإجابات المعاد إرجاعها.
- **زر الاعتماد الجماعي للدفعة (Batch Finalize Button)**: زر عالي الأمان يتطلب تأكيداً ثنائياً لإغلاق التقييم لكافة استجابات المادة ونشر النتائج للطلاب.

---

### 2.4. الرحلة الرابعة: رحلة مشغل الطوارئ (Admin Emergency Operator Journey)

```
[مركز الطوارئ والسجلات (Emergency Audit Center)]
       │
       ▼
[البحث عن إجابة معتمدة بـ UUID أو مفتاح الجلسة]
       │
       ▼
[استعراض السجل السلسلي التتابعي كاملًا (Append-Only Audit Inspector)]
       │
       ▼
[طلب فتح مراجعة استثنائية (Trigger Emergency Reopen)]
       │ (اشتراط إدخال سبب رسمي Reason لا يقل عن 20 حرفًا + رمز تحقق الطوارئ)
       ▼
[تسجيل صف مراجعة جديد في question_response_reviews وتوجيه الإجابة لـ Senior Grader]
```

---

### 2.5. الرحلة الخامسة: رحلة الطالب (Student Experience - Results & Appeal Flow)

```
[لوحة نتائج الطالب (Student Results Dashboard)]
       │ (تظهر فقط بعد Batch Finalization)
       ▼
[استعراض درجة السؤال المقالي + تفاصيل Rubric + ملاحظات المصحح]
       │
       ├── خيار أ: الرضا عن النتيجة واكتفاء الطالب
       └── خيار ب: تقديم اعتراض / تظلم (Submit Appeal)
           │
           ▼
     [نافذة إدخال مبررات الاعتراض والنقاط الخلافية]
           │
           ▼
     [متابعة حالة التظلم (قيد المراجعة -> تم القبول والتعديل / تم التأكيد)]
```

#### واجهة الطالب الخاصة بالنتيجة (Student Score View):
- **عرض الدرجة بوضوح**: بطاقة تعرض الدرجة المستحقة من الدرجة الكلية مع شريط تقدم ملون.
- **تفاصيل سلم التقييم (Rubric Breakdown)**: عرض النقاط التي حصل عليها الطالب في كل معيار فرعي مع شرح المصحح للأخطاء.
- **زر كشف الإجابة النموذجية (Reveal Model Answer)**: يفتح نافذة مقارنة بين إجابة الطالب والإجابة النموذجية بعد التاريخ والوقت المعتمدين للكشف.

## 3. مواصفات التجاوب والاستجابة اللمسية (Mobile & Touch Specifications)

| المكون (UI Component) | شاشات الهواتف (< 640px) | شاشات التابلت (640px - 1024px) | الشاشات الكبيرة (> 1024px) |
| :--- | :--- | :--- | :--- |
| **تخطيط صفحة التصحيح** | عمودي كامل (Single Column) مع درج سفلي | تخطيط مقسوم (Split View 50% / 50%) | تخطيط ثلاثي الأعمدة (Sidebar / Main / Rubric) |
| **سلم التقييم (Rubric)** | Drawer يتم سحبه من الأسفل عند الحاجة | panel ثابت في الجانب الأيسر | panel ممتد يمين الإجابة النموذجية |
| **أزرار إدخال الدرجات** | أزرار كبس كبيرة (Min Height 52px) | أزرار تفاعلية لمسية (Min 48px) | إدخال رقمي مباشر + أزرار Rubric |
| **الملاحة بين الإجابات** | الإيماء السريع (Swipe Left / Right) | أزرار الأسهم العائمة بالأفل | اختصارات لوحة المفاتيح (Shortcuts) |
