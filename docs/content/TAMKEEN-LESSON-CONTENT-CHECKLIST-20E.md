# نموذج تسليم محتوى الدرس (20E Checklist)

انسخ هذا النموذج لكل درس واملأه. المرجع الكامل: `TAMKEEN-YOUSUF-CONTENT-INTAKE-STANDARD-20E.md`.

**القيم المسموحة لكل قدرة:** `READY` | `DRAFT` | `REVIEW` | `MISSING_CONTENT` | `N/A_BY_LESSON`

---

### فحص الجودة قبل اعتماد كل قدرة

```text
SOURCE_MATCH=
CONTENT_COMPLETE=
RTL=
MOBILE=
ASSETS_PRESENT=
NO_EXTERNAL_BROKEN_URL=
NO_SCRIPT_RISK=
NO_HORIZONTAL_OVERFLOW=
```

```text
TEXT_FIDELITY=

ORDER_FIDELITY=
HUMAN_REVIEW=
```

