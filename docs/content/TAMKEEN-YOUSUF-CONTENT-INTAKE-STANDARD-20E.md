# TAMKEEN — معيار استلام وإدخال محتوى الدرس (20E)

**النوع:** توثيق تشغيلي فقط — `CODE_CHANGES=0`, `MIGRATIONS=0`, `RLS_RPC_CHANGES=0`, `PRODUCTION_CONTENT_WRITES=0`, `PUBLISH=0`.
**الجمهور:** يوسف (مسؤول إدخال المحتوى) — لا يحتاج SQL ولا أسماء جداول ولا أرقام قوالب.
**المصدر:** كل ما في هذه الوثيقة مُشتق من التنفيذ الفعلي (عقد القدرات، دورة الحياة 20C، مركز محتوى الدرس)، لا من افتراضات.

---

## 1. حزمة الدرس الكاملة (Canonical Lesson Package)

العناصر التي يستلمها يوسف ويدخلها لكل درس (9 عناصر):

| # | القدرة | الرمز |
|---|--------|-------|
| 1 | محتوى الكتاب الرسمي | 📖 |
| 2 | شرح تمكين | 👨‍🏫 |
| 3 | الخريطة الذهنية (HTML) | 🗺️ |
| 4 | المحاكاة / النشاط التفاعلي | 🧪 |
| 5 | الموارد المساعدة (فيديو/صوت/روابط) | 🎥 |
| 6 | المراجعة السريعة | 🧠 |
| 7 | أسئلة «اختبر فهمك» | ✅ |
| 8 | اختبار الدرس | 🏆 |
| 9 | نسخة الكتاب الأصلية PDF | 📚 |

**«مستواك وأخطاؤك» (📈) ليست مادة إدخال** — تُشتق آلياً من نشاط الطالب، ولا يظهر لها إدخال في مركز محتوى الدرس.

---

## 2. الإلزامي مقابل الاختياري

| القدرة | التصنيف | ملاحظة |
|--------|---------|--------|
| محتوى الكتاب الرسمي | **MANDATORY** | بدونه الدرس لا يُعتبر جاهزاً إطلاقاً (`BOOK_READY`) |
| شرح تمكين | **TARGET** | مطلوب لـ `LEARNING_READY` |
| المراجعة السريعة | **TARGET** | مطلوب لـ `LEARNING_READY` |
| اختبر فهمك | **TARGET** | مطلوب لـ `FULLY_READY` |
| PDF الأصلي | **REFERENCE / TARGET** | مرجع مستقل في نهاية الدرس |
| الخريطة الذهنية | **TARGET** | لا تمنع الجاهزية إن لم تناسب الدرس |
| اختبار الدرس | **TARGET** | حسب السياسة التعليمية للمادة |
| المحاكاة | **DEPENDS_ON_LESSON** | علمي/تطبيقي غالباً |
| الموارد المساعدة | **OPTIONAL** | |

**قاعدة حاكمة:** القدرات الأربع التي يحسبها النظام كـ«ناقص» هي فقط: محتوى الكتاب، شرح تمكين، المراجعة السريعة، اختبر فهمك. أي قدرة أخرى غير موجودة تُعرض **N/A_BY_LESSON (غير مطلوب لهذا الدرس)** ولا تمنع اكتمال الدرس.

---

## 3. الصيغ المقبولة (من الأنظمة القائمة فقط)

| القدرة | الصيغة المقبولة | مسار الإدخال |
|--------|------------------|---------------|
| محتوى الكتاب الرسمي | محتوى بنيوي معتمد وفق معيار 20A (بلوكات + أشكال) أو نص Markdown | مركز محتوى الدرس / قالب محتوى الكتاب |
| شرح تمكين | النموذج الحالي القائم (شرح نصي متعدد لكل درس بـ `explanation_code`) | حوار «إدارة الشروحات» |
| الخريطة الذهنية | **HTML** فقط، عبر خط أنابيب HTML القائم (بدون JS خارجي، بدون CDN، يُنقّى قبل العرض) | حوار الموارد / رفع HTML |
| المحاكاة | المسار الحالي الفعلي للمحاكاة/النشاط التفاعلي | مركز محتوى الدرس |
| الموارد المساعدة | video / mindmap / experiment / pdf / link مع رابط صالح إلزامي | حوار «إدارة الموارد» |
| المراجعة السريعة | نص المراجعة السريعة عبر مركز محتوى الدرس (نظام 15A) | حوار «المراجعة السريعة» |
| اختبر فهمك | بنك الأسئلة الحالي (استيراد/إدخال أسئلة مرتبطة بالدرس) | مسار بنك الأسئلة |
| اختبار الدرس | مسار التقييمات الحالي (اختبار مرتبط بالدرس ثم ربط الأسئلة) | مسار التقييمات |
| PDF الأصلي | ملف PDF مرفوع مباشرة ومرتبط بالدرس | الرفع المباشر 18D |

**ممنوع اختراع صيغة جديدة** ما دام النظام الحالي يدعم صيغة مناسبة.

## 4. تسمية الملفات

المفتاح الموحد هو **`lesson_code`** (وهو نفسه `slug` الدرس داخل المادة):

```text
lesson-g10-001-001.pdf     ← نسخة الكتاب الأصلية
lesson-g10-001-001.html    ← الخريطة الذهنية
lesson-g10-001-001-fig-01.png  ← شكل داخل المحتوى الرسمي
```

- كل ملف يبدأ بـ `lesson_code` الكامل، ثم لاحقة وصفية عند الحاجة، بحروف صغيرة وشرطات فقط.
- **ممنوع** الاعتماد على عنوان الدرس للمطابقة الجماعية — العناوين تتكرر وتتغير.
- في الاستيراد الجماعي يجب أن يوجد عمود `lesson_code` (مع `subject_code` عند الحاجة) في كل ملف.

## 5. مسار يوسف اليومي

```text
المادة
 → الدرس
 → مركز محتوى الدرس (/admin/lesson-content/{الدرس})
 → مراجعة مصفوفة الجاهزية (10 قدرات)
 → إضافة / استيراد العنصر
 → حفظ (مسودة DRAFT)
 → معاينة كطالب (تشمل المسودات)
 → إرسال للمراجعة (REVIEW)
 → اعتماد ونشر للطالب (READY)
```

يوسف **لا يحتاج**: SQL، RPC، اسم جدول، رقم نسخة، رقم قالب.

قواعد مهمة:
- بعد أي حذف أو تعديل داخل الحوار يجب الضغط على **حفظ** لتثبيت التغيير.
- تعديل قدرة معتمدة يُنشئ **نسخة مسودة جديدة**، والطالب يبقى يرى النسخة المعتمدة السابقة حتى يُعتمد التعديل — لا انقطاع للمحتوى.
- الانتقالات المسموحة: لا شيء→مسودة، مسودة→مراجعة، مراجعة→اعتماد أو رجوع لمسودة، معتمد→مسودة (تعديل جديد).

## 6. قائمة فحص الجودة قبل الاعتماد

لكل قدرة قبل الضغط على «اعتماد»:

```text
SOURCE_MATCH=            (يطابق المصدر المستلم)
CONTENT_COMPLETE=        (لا نقص ولا بتر)
RTL=                     (اتجاه عربي سليم)
MOBILE=                  (مقروء على الجوال)
ASSETS_PRESENT=          (كل الصور/الملفات تظهر)
NO_EXTERNAL_BROKEN_URL=  (لا روابط مكسورة)
NO_SCRIPT_RISK=          (لا JS خارجي ولا CDN داخل HTML)
NO_HORIZONTAL_OVERFLOW=  (لا تمرير أفقي)
```

إضافة للمحتوى الرسمي (📖 و📚):

```text
TEXT_FIDELITY=    (النص حرفي كما في الكتاب)
FIGURE_FIDELITY=  (الأشكال كاملة وفي مواضعها)
ORDER_FIDELITY=   (ترتيب البلوكات كما في الكتاب)
HUMAN_REVIEW=     (اسم المراجع + التاريخ)
```

## 7. معيار المراجعة السريعة (🧠)

المراجعة السريعة **طبقة تعلّم من إعداد تمكين، وليست نسخاً من الكتاب**.

يجب أن تكون قصيرة ومباشرة (قراءة ≤ 3 دقائق) وتغطي:
- أهم أفكار الدرس (3–7 نقاط).
- المفاهيم والتعريفات الأساسية.
- ما يجب تذكّره قبل الاختبار.
- أخطاء شائعة عند الحاجة.
- القوانين/القواعد حسب طبيعة المادة (رياضيات، كيمياء، تجويد…).

**حدود واضحة:**

| الطبقة | وظيفتها | ما لا تفعله |
|--------|---------|--------------|
| 📖 محتوى الكتاب | نص الكتاب الرسمي حرفياً | لا تلخيص ولا إضافة |
| 👨‍🏫 شرح تمكين | شرح مطوّل وتبسيط وأمثلة | ليس اختصاراً نهائياً |
| 🗺️ الخريطة الذهنية | تمثيل بصري للعلاقات | ليست نصاً متصلاً |
| 🧠 المراجعة السريعة | تذكير مكثّف قبل الاختبار | لا تنسخ الكتاب ولا «تقويم الكتاب» ولا تُعيد الشرح |

هذه الوثيقة تُعرّف المعيار فقط — ولا تؤلف محتوى درس القرآن.

## 8. مصفوفة الجاهزية

كما يحسبها النظام فعلياً:

```text
BOOK_READY     = محتوى الكتاب الرسمي معتمد (READY)
LEARNING_READY = BOOK_READY + شرح تمكين + المراجعة السريعة
FULLY_READY    = LEARNING_READY + اختبر فهمك
```

قراءة الحالات في المصفوفة:

| ما يظهر | معناه | الإجراء |
|---------|-------|---------|
| جاهز (READY) | معتمد ويظهر للطالب | لا شيء |
| مسودة | مُدخل ولم يُعتمد بعد | أكمل المسار حتى الاعتماد |
| قيد المراجعة | بانتظار قرار المراجع | اعتماد أو إرجاع لمسودة |
| ناقص (MISSING) | قدرة مطلوبة لم تُدخل | **مهمة محتوى** على يوسف |
| غير مطلوب لهذا الدرس (N/A) | قدرة غير مناسبة للدرس | تجاهلها |
| بيانات غير صالحة | مُدخل لكن الرابط/المحتوى غير سليم | صحّح المصدر |

**تمييز إلزامي:** «ناقص» = `MISSING_CONTENT` (نقص محتوى)، وليس `SYSTEM_ERROR`. لا يُفتح بلاغ تقني إلا عند رسالة خطأ فعلية أو فشل حفظ.

## 9. مساران للإدخال

**أ) درس مفرد (الأساسي اليوم):** من مركز محتوى الدرس، قدرة قدرة، بنفس مسار §5.

**ب) استيراد جماعي:** بالمستوردات القائمة (المواد → الوحدات → الدروس → محتوى الكتاب → الشروحات → الموارد → التقييمات → بنك الأسئلة → ربط الأسئلة)، والمفتاح دائماً `lesson_code` (+ `subject_code`). المحتوى المستورد يدخل كمسودة ويظل يمر بمسار الاعتماد نفسه.

> لا يُنفَّذ أي استيراد جماعي جديد ضمن 20E — توثيق فقط.

## 10. خريطة: ما يدخله يوسف ← ما يراه الطالب

ترتيب صفحة الدرس عند الطالب ثابت ومعتمد:

| # | القدرة | مصدر الإدخال | متى تظهر |
|---|--------|---------------|-----------|
| 1 | محتوى الكتاب الرسمي | محتوى الكتاب | عند الاعتماد (READY) |
| 2 | شرح تمكين | الشروحات | عند الاعتماد |
| 3 | الخريطة الذهنية | مورد HTML | عند الاعتماد |
| 4 | المحاكاة | المحاكاة | عند الاعتماد |
| 5 | الموارد المساعدة | الموارد | عند الاعتماد |
| 6 | المراجعة السريعة | المراجعة السريعة | عند الاعتماد |
| 7 | اختبر فهمك | بنك الأسئلة | عند الاعتماد |
| 8 | اختبار الدرس | التقييمات | عند الاعتماد |
| 9 | مستواك وأخطاؤك | — مشتقة آلياً | تلقائياً مع نشاط الطالب |
| 10 | نسخة الكتاب الأصلية PDF | رفع PDF | عند الاعتماد |

قواعد الظهور (Fail-Closed):
- **DRAFT / REVIEW** → مخفي عن الطالب، إلا إذا كانت هناك نسخة معتمدة سابقة فيبقى الطالب يراها.
- **READY** → ظاهر للطالب.
- **المعاينة كطالب** (`?preview=1`) تُظهر المسودات للطاقم فقط مع شارة «معاينة» — الطالب لا يصل إليها.
