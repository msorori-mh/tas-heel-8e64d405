
## Post-Verify — جلسة طالب نقي (بدون أي أدوار)

| Gate | النتيجة | الدليل |
|---|---|---|
| G4 عزل الفصل الأول | PASS | القرآن: الجزء الأول فقط في `/semesters/1`؛ الرياضيات: الجزء الأول + كتاب التمارين |
| G5 عزل الفصل الثاني | PASS | القرآن: الجزء الثاني فقط؛ الرياضيات: الجزء الثاني + كتاب التمارين |

### ملاحظة مفتوحة (Cold-start offline)
إذا نزّل الطالب الكتاب ثم انقطع الإنترنت **قبل** فتحه ولو مرة واحدة، تفشل أول محاولة فتح لأن حزمة القارئ (chunk + محرك pdf.js) لم تُحمَّل بعد. أُضيف تجهيز مسبق (`prefetchPdfViewerChunk`) عند التنزيل/الكاش، لكنه لم يُثبت فعاليته في بيئة التطوير (Vite يقدّم الوحدات غير مجمّعة). يوصى بإعادة قياسه على بناء الإنتاج / Android قبل اعتماده مغلقاً.

**الحكم:** PASS_WITH_ONE_OPEN_ITEM (cold-start offline chunk warm-up).
