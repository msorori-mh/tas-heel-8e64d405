## Checklist اليدوي (إلزامي — 14 بنداً)

| # | الخطوة | النجاح المتوقع |

- [ ] ظهور مادة مقسّمة كمواد منفصلة مكررة (يدل على هجاء غير موحد).

## الاختبار الهيكلي (اختياري — skeleton)

`tests/smoke/student-limited-release.smoke.test.mjs`:

```bash
# يتخطى بوضوح دون بيانات اعتماد:
node --test tests/smoke/student-limited-release.smoke.test.mjs

# عند توفر حساب اختبار موجود مسبقاً:
SMOKE_STUDENT_EMAIL=... SMOKE_STUDENT_PASSWORD=... node --test tests/smoke/student-limited-release.smoke.test.mjs
```

خصائصه:
- **يتخطى (skip) برسالة واضحة** إذا غابت `SMOKE_STUDENT_EMAIL`/`SMOKE_STUDENT_PASSWORD`.
- عند توفرها: تسجيل دخول قراءة فقط + جلب مواد الطالب + التحقق أن حمولة الأسئلة (عبر RPCs العامة) لا تتضمن مفاتيح الإجابة.
- **لا يكتب أي بيانات** ولا يبدأ جلسات اختبار ولا يستورد.
