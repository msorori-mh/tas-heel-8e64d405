## 1. نظرة عامة على كتالوج البرامج

تتكون البرامج التدريبية في أكاديمية المعلمين من 19 برنامجاً رئيسياً تنقسم إلى:
- **9 برامج تأسيسية تربوية:** تغطي الكفايات التربوية العامة والتشخيص والقيادة الصفية.
- **10 برامج تخصصية:** تغطي المواد الدراسية الرئيسية لمرحلة الثانوية.

---

## 2. التاكسونومي الهرمي القياسي (S1 Educational Model)

تعتمد جميع البرامج والمقررات الهيكل القياسي الموحد:
```
academy_programs -> academy_program_versions -> academy_courses -> academy_modules -> academy_lessons -> academy_cohorts
```

> **ملاحظة إزالة التاكسونومي القديم:** تم الاستغناء الكلي عن المسميات القديمة مثل `ta_paths` أو `ta_modules` أو `ta_lessons`.

## 5. مصفوفة التقييم التشخيصي والربط بالدفعات

ترتبط البرامج التدريبية ومقرراتها بمجالات التشخيص الثمانية لبناء الخارطة المهارية التلقائية المعززة بـ `academy_cohorts`:
1. التخطيط والتصميم التدريسي.
2. إدارة البيئة الصفية.
3. التقييم والتشخيص.
4. تكنولوجيا التعليم.
5. استراتيجيات التدريس.
6. الفروق الفردية والرعاية.
7. المهارات التخصصية.
8. التطوير المهني والبحث الإجرائي.

- **التسجيل والالتحاق:** يتم حصراً عبر الدفعات التدريبية المعتمدة `academy_cohorts`.
- **بيانات Seed والمهام:** المهام TA-091 إلى TA-096 تضمن الجاهزية التربوية والتشغيلية بنطاق MVP (85) / P1 (15) / P2 (10).
