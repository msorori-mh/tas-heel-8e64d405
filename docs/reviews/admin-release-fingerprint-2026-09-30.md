خط الأساس `ec1d73b2c0ef65759ab2f28db3d14285c3903d27`، والفرع `fix/admin-release-fingerprint`. التفويض: إصلاح الخطأ الظاهر في لوحة الإدارة، مع استمرار تفويض رفع إصلاحات الموقع ونشرها. بناء أندرويد مؤجل. لا قاعدة بيانات أو صلاحيات أو سجلات مستخدمين ضمن التغيير.

## الإصلاح

- يحسب البناء بصمة SHA-256 فعلية للملفات تحت `src` و`public` ومصادر وأصول أكاديمية المعلمين وأداة الإصدار، وملفات الاعتماديات وإعدادات البناء المحددة في `scripts/release/build-release.ts`.
- الخوارزمية `tamkeen-web-source-v1`: قائمة مرتبة للمسارات وبصمة محتوى كل ملف. لا يدخل فيها مسار الجهاز أو أوقات الملفات أو Git أو `.env` أو `node_modules` أو نواتج البناء أو التوثيق. هذه بصمة ملفات المصدر، وليست ادعاءً بأنها معرّف التزام Git أو بصمة حزمة النشر الثنائية أو إعدادات البيئة.
- تستخدم اللوحة معرّف Git الصحيح إذا توفر، وإلا تعرض البصمة المحسوبة باسم «بصمة ملفات المصدر (SHA-256)». لا رقم ثابت أو مختلق، ويبقى التحذير عند غياب الهويتين الصالحتين.
- تُرفض المدخلات الناقصة والروابط الرمزية بدلاً من إصدار بصمة ناقصة. ولا تستعير نسخة الأرشيف معرّف Git من مستودع أب.
- الإعدادات والتشخيص تستخدمان `shortId` بحيث تصبح النسخ بلا Git قابلة للتمييز أيضاً. لا تغيير لإصدار APK/AAB.
