# تمكين الطالب — مسودة Data safety

هذه خريطة تنفيذية مبنية على مصدر الإصدار الحالي وليست إقرارًا نهائيًا بالنيابة عن مالك حساب Play. يجب مطابقتها مع إعدادات Supabase وCloudflare وLovable الإنتاجية واتفاقيات مزودي الخدمة قبل الضغط على Submit.

## إجابات مستوى التطبيق

| السؤال                                  | المسودة                                                | الدليل / الإجراء المتبقي                                                              |
| --------------------------------------- | ------------------------------------------------------ | ------------------------------------------------------------------------------------- |
| هل يجمع التطبيق أو يشارك بيانات مستخدم؟ | نعم — يجمع بيانات الحساب والنشاط الدراسي لتقديم الخدمة | الحساب والتقدم والاختبارات مخزنة في Supabase                                          |
| هل البيانات مشفّرة أثناء النقل؟         | نعم                                                    | أصل HTTPS فقط، mixed content وcleartext معطّلان؛ يجب التحقق من شهادة الإنتاج          |
| هل يستطيع المستخدم طلب حذف البيانات؟    | نعم                                                    | داخل التطبيق: الإعدادات → الأمان والحساب → حذف الحساب. خارج التطبيق: `/data-deletion` |
| هل يحتوي إعلانات؟                       | لا                                                     | لا SDK إعلاني ولا صلاحية Advertising ID في مصدر Android الحالي                        |
| هل تُشارك البيانات لأغراض إعلانية؟      | لا                                                     | لا إعلانات أو SDK تسويق ظاهر في المصدر                                                |
| هل توجد مشتريات داخل التطبيق؟           | لا في الإصدار الحالي                                   | `STUDENT_FREE_ACCESS=true` ومسارات الدفع تعرض إغلاق الخدمة                            |

## مزودو الخدمة

| المزود                      | الاستخدام في الإصدار                                             | ما يجب التحقق منه قبل Submit                                 |
| --------------------------- | ---------------------------------------------------------------- | ------------------------------------------------------------ |
| Supabase                    | المصادقة، قاعدة البيانات، التخزين                                | المناطق، الاحتفاظ، سجلات Auth، DPA، حذف المستخدم             |
| Cloudflare                  | الاستضافة والحماية والتسليم                                      | سجلات IP/User-Agent، مدة الاحتفاظ، Analytics المفعّلة فعليًا |
| Google OAuth                | تسجيل الدخول الاختياري                                           | بيانات النطاقات المطلوبة فقط ومسار حذف مستخدم Google         |
| Lovable AI Gateway / Gemini | مسار OCR موجود في المصدر لكنه غير قابل للوصول في الإصدار المجاني | تأكيد عدم استدعائه، وإعادة Data safety قبل أي تفعيل مستقبلي  |

## بوابة الإقرار النهائي

- [ ] فتح النسخة الموقعة من Internal testing وتسجيل كل طلب شبكة لطالب جديد.
- [ ] مطابقة الطلبات مع جرد الفئات أعلاه ومراجعة أي SDK يضاف إلى AAB النهائي.
- [ ] تأكيد أن Supabase وCloudflare يُعاملان كمزودي خدمة وفق شروط Play، وإلا تعدّل خانة Sharing.
- [ ] اختبار حذف حساب بريد وحساب Google، والتأكد من زوال الملف والتقدم وملفات المستخدم.
- [ ] التحقق من عمل رابطَي الخصوصية والحذف دون تسجيل دخول ومن خارج التطبيق.
- [ ] حفظ نسخة PDF/لقطة من إجابات Play Console المعتمدة مع رقم الإصدار وتاريخه خارج Git إذا احتوت بيانات حساسة.
