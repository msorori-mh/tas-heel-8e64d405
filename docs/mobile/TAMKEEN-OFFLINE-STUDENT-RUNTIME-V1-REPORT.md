# تمكين بلا نت — Student Runtime V1

## قرار المرحلة

**الهدف:** تمكين الطالب من تنزيل حزمة مادة موثّقة، فتح محتوى الدروس والتقييمات المحمّلة بعد انقطاع الشبكة أو التشغيل البارد على Android، ثم مزامنة النشاط مرة واحدة عند عودة الاتصال.

**لا يشمل:** الإدارة والأكاديمية، اختلاق محتوى، نشر محتوى وزاري، أو اعتبار اختبار المحاكي بديلًا عن اختبار وضع الطيران على جهاز فعلي.

## ما تنفذه الدفعة

- Manifest مرتبط بالصف، المسار، الفصل والمادة، وبصمة SHA-256 مستقلة لكل artifact.
- تنزيل قابل للاستكمال مع فحص الحجم والبصمة قبل اعتماد الحزمة `ready`.
- تخزين خاص بالحساب؛ لا تُفتح حزمة حساب لطالب آخر.
- عرض حالة الحزمة من صفحة المادة، مع تنزيل/تحديث/حذف واضح.
- قراءة HTML وPDF والمراجعة السريعة والتقييمات المحمّلة دون اتصال.
- شاشة Android مضمّنة لفتح الدرس المحمّل عند فشل الأصل البعيد في التشغيل البارد.
- سجل تعلم محلي وOutbox بمفتاح idempotency، lease محدود، retry متدرج، وحذف بعد تأكيد الخادم.
- مزامنة التقدم وإكمال الدرس وإجابات أسئلة الكتاب عبر RPC موحّد.

## ضمانات الأمان والبيانات

- لا تحفظ الحزم tokens أو cookies أو كلمات مرور أو signed URLs أو service-role keys.
- لا تُقبل ملفات خارج الجذر الخاص بالحساب، ولا مسارات مطلقة أو traversal.
- لا تُعرض إجابات التقييمات إلا من طبقة server-only مرتبطة بالمراجعة المنشورة والدرس.
- `lesson-progress` يكتب `progress_percent` ولا يلمس `quiz_score`.
- كل mutation يتحقق من وصول الطالب؛ وإجابة سؤال الكتاب تُربط بالسؤال والدرس والمراجعة المنشورة.
- إعادة نفس idempotency key تعيد النتيجة السابقة؛ payload مختلف للمفتاح نفسه يُرفض.
- الساعة المستقبلية على الجهاز تُقيد بوقت الخادم، والحدث الأقدم لا يستبدل حالة أحدث.
