# FIRST-PRODUCTION-BATCH-CHECKLIST-10 — قائمة أول دفعة محتوى حقيقية

> **لا تُنفَّذ هذه القائمة إلا بتفويض مكتوب من المالك.** القاعدة مشتركة مع الموقع المنشور:
> أي كتابة هنا كتابة إنتاجية.

## نطاق الدفعة الأولى (ثابت، غير قابل للتوسيع)

```text
مادة واحدة
→ وحدة واحدة
→ درس واحد
→ محتوى/شرح
→ موارد
→ تقييم واحد

NO QUESTIONS      (القالب 09 محظور)
NO ASSESSMENT-QUESTION LINKS
NO PUBLISH
```

## قبل التنفيذ

- [ ] تفويض مكتوب من المالك مسجَّل في المحادثة.
- [ ] ملف/ملفات الدفعة نهائية ومحفوظة خارج التطبيق (بصمة الملف مسجّلة).
- [ ] عدد صفوف كل قالب ≤ 50 في هذه الدفعة.
- [ ] لا مهمة استيراد أخرى قيد التشغيل (`import_jobs` كلها بحالة نهائية).
- [ ] Baseline counts محفوظة (انظر جدول المرحلة 10).
- [ ] Logical snapshot لأي صف سيُحدَّث (`UPDATE_DRAFT`) — مطابقة بالمفاتيح الطبيعية قبل التنفيذ.
- [ ] المشغّل يملك `admin` أو `content_manager` فقط، ولا يملك أي capability نشر.

## التنفيذ

- [ ] Dry-run أولاً — صفر أخطاء وصفر تحذيرات تسمية.
- [ ] Prepare (staging) بنفس الملف وبصمته.
- [ ] Execute بترتيب التبعية المعتمد (`IMPORT_EXECUTION_ORDER`) — لا ترتيب رقمي.
- [ ] تسجيل `job_id` الناتج في سجل التشغيل.

## بعد التنفيذ — تحقق إلزامي

- [ ] `import_jobs` للمهمة = `completed`، و`import_errors` = 0.
- [ ] فروق العدّادات تطابق المتوقع بالضبط (لا صف زائد).
- [ ] فحص Admin: المادة/الوحدة/الدرس/الموارد/التقييم تظهر صحيحة في لوحة التحكم.
- [ ] فحص طالب حقيقي (حساب طالب فعلي بصفّه ومنهجه):
  - [ ] يرى المحتوى المقصود فقط ضمن صفّه ومساره.
  - [ ] لا يرى أي مسودة.
  - [ ] لا تسريب إجابات في أي استجابة.
- [ ] فحص زائر (غير مسجّل): لا يرى شيئاً من محتوى الدفعة.

## معايير التراجع

يُنفَّذ Rollback فوراً إذا تحقق أي مما يلي:

- ظهور محتوى لغير الصف/المسار المستهدف.
- ظهور مسودة لطالب.
- فرق عدّادات غير مفسَّر.
- أي خطأ في القالب الأخير يترك حالة غير مفهومة.

خطوات التراجع: حذف عكسي لصفوف `INSERT` بأكواد الدفعة، ثم إعادة قيم `UPDATE_DRAFT`
من الـ logical snapshot. `import_jobs` / `import_errors` لا تُحذف.

## بوابة التوسّع

لا دفعة ثانية أوسع قبل: نجاح هذه الدفعة + اكتمال فحص Admin والطالب + قرار مالك مكتوب.
دخول الأسئلة والتقييمات المرتبطة بها مشروط بإغلاق `G1_PUBLISHED_REVISION_TARGET_BINDING_11`.
