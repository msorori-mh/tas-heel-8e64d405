# دليل تشغيل إدخال المحتوى (OPERATOR RUNBOOK)

مرحلة: CURRICULUM_CONTENT_ENTRY_READINESS_13

## قبل البدء

- الصلاحية المطلوبة: `content_manager` (يستورد ويعاين) أو `admin` (يستورد ويحذف).
- نزّل **حزمة المشغّل الرسمية (ZIP)** من مركز الاستيراد: تحتوي القوالب التسعة والأدلة الثلاثة.
- راجع `docs/import/NAMING-CONVENTION.md` قبل كتابة أي كود.
- راجع `docs/import/DATA-DICTIONARY-AR.md` لمعاني الأعمدة.
- راجع `docs/import/CONTENT-MANAGER-PERMISSION-MATRIX.md` لمعرفة حدود صلاحيتك.

## الخطوات

1. **تنزيل القوالب** من: لوحة الإدارة ← مركز الاستيراد (أو من حزمة المشغّل).
2. **تعبئة القالب 01** (المواد) فقط أولاً — لا تفتح بقية القوالب قبل نجاحه.
3. **معاينة (Dry-Run)**: ارفع الملف واقرأ النتيجة:
   - `سيُضاف` / `سيُحدَّث` / `سيُتجاهل` / `محجوب (منشور)` / `أخطاء`.
4. إذا ظهرت أخطاء: صحّح الملف وأعد المعاينة. **لا تنفّذ مع وجود أخطاء.**
5. **تنفيذ**: بعد معاينة نظيفة فقط.
6. تحقّق من النتيجة في **سجل عمليات الاستيراد** (القالب، الملف، الصفوف، مُدرج، مُحدّث، متجاوَز، محجوب، أخطاء، الحالة، المشغّل، التاريخ).
7. كرر الخطوات 2–6 بالترتيب الرسمي: 01 → 02 → 03 → 04 → 05 → 06 → 07 → **مراجعة ← نشر** → 09 → 08.

## بوابة المراجعة والنشر قبل القالب 08

القالب 08 (ربط أسئلة التقييم بالدروس) لا يعمل على أسئلة مسودة. قبل تشغيله:

1. نفّذ القالب 09 لإنشاء الأسئلة كمسودات (Draft Revision).
2. **المراجعة**: راجع الأسئلة وحالة المحتوى — هذه صلاحية `content_manager`.
3. **النشر**: نشر مراجعة السؤال يتم بقدرة صريحة لدى المشرف الكامل فقط.
4. بعد النشر فقط، شغّل القالب 08 لربط الأسئلة المنشورة بالدروس.

إذا شغّلت 08 قبل النشر ستظهر صفوف مرفوضة لأن السؤال غير منشور.


## حالات شائعة

| الحالة | السبب | الحل |
|---|---|---|
| `SUBJECT_NOT_FOUND` | لم يُنفَّذ القالب 01 بعد، أو الكود مختلف | نفّذ 01 أولاً وطابق الكود حرفياً |
| صفوف «محجوبة» | الكيان منشور ومحمي من التعديل | أوقف النشر أولاً أو اترك الصف كما هو |
| ظهور المادة مرتين للطالب | اختلاف هجاء `group_name` بين الأقسام | وحّد `group_name` لكل الأقسام |
| «لا يمكن تغيير كود المجموعة» | `group_code` مُعيَّن مسبقاً | الكود ثابت — تواصل مع المسؤول التقني |

## الحذف

- من: لوحة الإدارة ← المنهج / المواد / الوحدات / الدروس ← زر «حذف».
- يظهر أولاً **معاينة الأثر** (عدد الكيانات التابعة).
- الحذف يُمنع تلقائياً إذا وُجد أي نشاط طالب مرتبط.
- `content_manager` يرى المعاينة فقط؛ التنفيذ لمسؤول النظام الكامل.
