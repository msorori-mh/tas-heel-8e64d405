# OFFICIAL_CONTENT_CODE_SYSTEM_13B — تقرير الإغلاق

**النتيجة:** PASS — أكواد المحتوى أصبحت **System-owned** بمخطط رسمي مُصدَّر `TCS-1`.

## ما تغيّر

| قبل | بعد |
|---|---|
| موظف المحتوى يخترع الكود يدوياً (`arabic-g10-nahw`) | النظام يولّد الكود (`sub-g10-aden-002`) |
| الكود مشتق من الاسم → يتغيّر مع الاسم | الكود موضعي ومستقل عن الاسم |
| كود الدرس يحتوي كود الوحدة (`…-u01-l03`) | كود الدرس مستقل عن الوحدة → النقل بين الوحدات آمن |
| كود السؤال يحتوي الدرس | كود السؤال ثابت عبر المراجعات والاستهداف |
| القوالب فارغة يملؤها المشغّل | قالب مُعبّأ بالأكواد والمفاتيح الأب + ورقة «مرجع الأكواد» |

## المكوّنات المنفّذة

1. `src/lib/content-codes/tcs1-master-data.ts` — لقطة البيانات المرجعية الرسمية
   (grades / curriculum_tracks). أي صف أو مسار خارجها **يُرفض**.
2. `src/lib/content-codes/tcs1.ts` — الصيغ، البناء، التحليل، التحقق، والتخصيص
   (دوال نقية بلا قاعدة بيانات). fail-closed عند تجاوز السعة أو تعارض كود.
3. `src/lib/content-codes/content-code-registry.server.ts` — قراءة فقط لسجل
   الأكواد القائمة وحساب الرقم التالي لكل نطاق. صفر كتابة، صفر ترحيل.
4. `src/lib/content-codes/contextual-template.server.ts` — بناء ملف Excel:
   ورقة تعليمات + ورقة **مرجع الأكواد** + ورقة بيانات معبّأة مسبقاً.
5. `src/lib/content-codes/content-codes.functions.ts` — دالتا خادم للقراءة فقط
   محميّتان بـ `requireContentStaffAuth`.
6. `src/components/admin/ContextualTemplateGenerator.tsx` — واجهة الاختيار
   (صف ← مسار ← مادة ← وحدة) داخل «مركز الاستيراد».
7. القوالب التسعة (01–09) أعيد توليدها: أمثلتها كلها بصيغة TCS-1 وكل ملف يحمل
   ورقة «مرجع الأكواد».
8. حزمة المشغّل صارت أربعة أدلة بإضافة `OFFICIAL-CONTENT-CODE-REGISTRY.md`.

## الأمان والحدود

- لا ترحيل قاعدة بيانات ولا sequence: التخصيص محسوب من الأكواد القائمة.
- الدوال محميّة بصلاحية فريق المحتوى؛ لا كتابة على أي جدول محتوى.
- عقد الاستيراد المركزي (`import-contract.ts`) هو مصدر أعمدة القالب المولّد،
  فلا يمكن أن ينحرف القالب الجاهز عن العقد.
