# مرجع الأكواد الرسمي — TCS-1

مرحلة: OFFICIAL_CONTENT_CODE_SYSTEM_13B

**القاعدة الحاكمة:** أكواد المحتوى **يملكها النظام** (System-owned). موظف المحتوى
لا ينشئ كوداً يدوياً ولا يعدّل كوداً موجوداً.

## من أين تأتي الأكواد؟

من «مركز الاستيراد» → قسم **قالب جاهز بأكواد النظام**:

1. اختر: الصف ← المسار ← (المادة ← الوحدة عند الحاجة).
2. اختر القالب وعدد الصفوف.
3. نزّل الملف: أعمدة الأكواد والمفاتيح الأب **معبأة مسبقاً**.
4. املأ النص العربي فقط، ثم ارفع الملف في مسار: فحص ← تجهيز ← تنفيذ.

## صيغ الأكواد (TCS-1)

| الكيان | الصيغة | مثال |
|---|---|---|
| مادة | `sub-{gradeShort}-{trackCode}-{subjectNo:003}` | `sub-g10-aden-003` |
| مجموعة مواد | `grp-{gradeShort}-{trackCode}-{groupNo:02}` | `grp-g10-aden-01` |
| وحدة | `unit-{gradeShort}-{trackCode}-{subjectNo:003}-{unitNo:02}` | `unit-g10-aden-003-02` |
| درس | `lesson-{gradeShort}-{trackCode}-{subjectNo:003}-{lessonNo:003}` | `lesson-g10-aden-003-004` |
| شرح | `exp-…-{lessonNo:003}-{seq:02}` | `exp-g10-aden-003-004-01` |
| مورد | `res-…-{lessonNo:003}-{seq:02}` | `res-g10-aden-003-004-01` |
| تقييم | `asm-…-{lessonNo:003}-{seq:02}` | `asm-g10-aden-003-004-01` |
| سؤال | `q-{gradeShort}-{trackCode}-{subjectNo:003}-{questionNo:05}` | `q-g10-aden-003-00007` |

## قواعد ثابتة

1. **الكود مستقل عن الاسم**: تغيير الاسم العربي لا يغيّر الكود إطلاقاً.
2. **الدرس لا يعتمد على الوحدة**: كود الدرس لا يحتوي كود الوحدة، فيمكن نقل الدرس
   بين الوحدات دون فقد هويته أو كسر الأسئلة المرتبطة به.
3. **السؤال لا يعتمد على الدرس**: هوية السؤال ثابتة عبر المراجعات والاستهداف.
4. **مصدر الصف والمسار هو البيانات المرجعية الحقيقية فقط** (`grades.slug`،
   `curriculum_tracks.track_code`) — لا قيم مخترعة.
5. **لا إعادة استخدام**: أي رقم خُصّص لا يُمنح لكيان آخر حتى بعد الحذف.
6. **الترقيم بخانات ثابتة** لضمان الترتيب: 3 خانات للمادة والدرس، خانتان للوحدة
   والتسلسل، 5 خانات للسؤال.

## كيف يُحسب الرقم التالي؟

النظام يقرأ الأكواد الموجودة فعلياً (قراءة فقط، بدون أي كتابة)، يستخرج أعلى رقم
داخل النطاق نفسه، ثم يمنح ما بعده. لا يوجد sequence في قاعدة البيانات ولا
ترحيل مطلوب، ولذلك لا يمكن أن يتعارض التخصيص مع كود قائم.

## الأكواد القديمة

أي كود لا يطابق TCS-1 يظهر في سجل الأكواد ضمن `nonConformingCodes`. لا يُعاد
ترميز المحتوى المنشور تلقائياً؛ TCS-1 يسري على كل ما يُدخَل من الآن فصاعداً.
