## قواعد ذهبية

1. لا تُنفّذ قالباً قبل نجاح ما يسبقه.
2. كل تنفيذ يبدأ بمعاينة (Dry-Run) وتُقرأ نتيجتها قبل الاعتماد.
3. إعادة رفع نفس الملف لا تُنشئ تكراراً (Idempotent) — الأكواد هي المفتاح.
4. المحتوى المنشور محمي: التعديل عليه يُحجب ويظهر ضمن `blocked_published`.
5. الحذف من لوحة الإدارة فقط، وبعد معاينة الأثر، ويُمنع إذا وُجد نشاط طالب.
